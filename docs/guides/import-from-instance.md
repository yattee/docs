# Importing from Invidious or Piped

If you have an Invidious or Piped account with existing subscriptions, you can import them into Yattee.

## Import Subscriptions

1. Go to **Settings > Sources** and tap the Invidious or Piped instance you want to import from.
2. In the **Account** section, tap **Log in to Account**, enter your credentials and tap **Sign In**.
3. Once signed in, an **Import** section appears. Tap **Subscriptions**.
4. If you have more than one place subscriptions can go, choose it with the **Account** picker. See [Accounts](../app/sources/remote-servers.md#accounts).
5. Yattee fetches your subscriptions from the instance and displays them as a list. Each channel shows its name, avatar, and subscriber count.
6. Tap the **+** button next to a channel to add it, or tap **Add All** in the toolbar to import everything at once.

## Import Playlists

From the same **Import** section, tap **Playlists** to bring over your playlists. The flow works the same way — browse the list and add individually or all at once.
